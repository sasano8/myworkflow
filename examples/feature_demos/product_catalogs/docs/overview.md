# サンプル銀行：業務要求の概要

架空の銀行を例に、保険商品と融資商品の業務要求をまとめた入口です。

このルートは銀行全体を表し、その配下の要求カタログが商品ごとの業務を表します。

## 対象業務

| 要求カタログ | 業務 | 主な処理 |
| --- | --- | --- |
| [保険商品](catalogs/product.insurance/workflows.md) | 保険申込の業務 | 申込内容の確認 → 保険料の算定 → 審査資料の作成 |
| [融資商品](catalogs/product.loan/workflows.md) | 融資申込の業務 | 申込内容の確認 → 返済計画の計算 |

## 銀行全体と商品の関係

- ルートカタログ：サンプル銀行。商品別の要求カタログを一覧にまとめます。
- 要求カタログ：保険商品・融資商品。ワークフロー、処理、データ、担当ロールを商品ごとに管理します。
- 商品内の詳細：ワークフロー一覧から専用詳細ページ、処理・ロール・データの共有定義へ進みます。

商品ごとに要求カタログを分けるため、同じワークフローIDでも別の業務を表せます。保険商品の `w.main` は保険申込、融資商品の `w.main` は融資申込の業務です。

## 共通の担当

- 業務担当者：商品運用部の業務担当者。各商品の処理を依頼します。
- システム：商品業務システム。商品内の各処理を担当します。

これらは銀行共通の[ロール定義](../shared.py)を商品別カタログから参照しています。

## このサンプルの範囲

保険申込の確認・保険料算定・審査資料作成と、融資申込の確認・返済計画計算を定義します。実行ハンドラーや商品間の業務接続、受入条件は未定義です。預金・振込・顧客管理など、銀行の他の業務はこのサンプルの対象に含めていません。

要求カタログは業務定義の整理単位です。実行負荷・データ・権限の分離は別途設計します。
